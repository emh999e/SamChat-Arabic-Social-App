# سام شات - SamChat

## منصة التواصل الاجتماعي العربية الأصيلة

**سام شات** هو تطبيق ويب للتواصل الاجتماعي مصمم خصيصاً للمجتمع العربي، يجمع بين الأصالة والحداثة في تجربة مستخدم متميزة.

### ✨ الميزات الرئيسية

- **تصميم عربي أصيل**: واجهة مستخدم تدعم اللغة العربية بالكامل مع اتجاه RTL
- **خطوط عربية جميلة**: استخدام خطوط Cairo وAmiri لتجربة قراءة مريحة
- **ألوان دافئة**: لوحة ألوان مستوحاة من التراث العربي (ذهبي، برتقالي، أحمر)
- **تفاعل اجتماعي**: إنشاء المنشورات، الإعجابات، التعليقات
- **قاعدة بيانات متقدمة**: مدعوم بـ Supabase للأداء العالي والأمان
- **تصميم متجاوب**: يعمل بسلاسة على جميع الأجهزة

### 🛠️ التقنيات المستخدمة

#### الواجهة الأمامية (Frontend)
- **React 19**: إطار العمل الحديث لبناء واجهات المستخدم
- **Tailwind CSS**: للتصميم السريع والمرن
- **Lucide React**: مكتبة الأيقونات الحديثة
- **Supabase Client**: للتواصل مع قاعدة البيانات

#### الخادم الخلفي (Backend)
- **Flask**: إطار عمل Python خفيف وقوي
- **Supabase**: قاعدة بيانات PostgreSQL مع ميزات الوقت الفعلي
- **Flask-CORS**: للسماح بالطلبات من مصادر متعددة

#### قاعدة البيانات
- **PostgreSQL**: عبر Supabase
- **Row Level Security (RLS)**: لحماية البيانات
- **Real-time subscriptions**: للتحديثات الفورية

### 🚀 التشغيل والتطوير

#### متطلبات النظام
- Node.js 18+ 
- Python 3.11+
- حساب Supabase

#### إعداد قاعدة البيانات
1. إنشاء مشروع جديد في [Supabase](https://supabase.com)
2. تشغيل محتوى ملف `supabase-schema.sql` في SQL Editor
3. الحصول على URL ومفاتيح API من إعدادات المشروع

#### إعداد متغيرات البيئة
إنشاء ملف `.env` في المجلد الرئيسي:
```env
REACT_APP_SUPABASE_URL=your-supabase-url
REACT_APP_SUPABASE_ANON_KEY=your-anon-key
SUPABASE_URL=your-supabase-url
SUPABASE_KEY=your-service-role-key
SUPABASE_JWT_SECRET=your-jwt-secret
```

#### تشغيل الواجهة الأمامية
```bash
# تثبيت التبعيات
pnpm install

# تشغيل خادم التطوير
pnpm run dev
```

#### تشغيل الخادم الخلفي
```bash
cd arabic-social-backend

# تفعيل البيئة الافتراضية
source venv/bin/activate

# تشغيل الخادم
python src/main.py
```

#### الخطوط
- **Cairo**: الخط الأساسي للنصوص العربية
- **Amiri**: للعناوين والنصوص المميزة
- **Noto Sans Arabic**: خط احتياطي

#### المكونات الرئيسية
- **الشريط العلوي**: شعار التطبيق وشريط البحث
- **الشريط الجانبي**: الملف الشخصي والإحصائيات
- **منطقة المنشورات**: إنشاء ومشاهدة المنشورات
- **التذييل**: معلومات التطبيق

### 🔐 الأمان والخصوصية

- **مصادقة آمنة**: نظام JWT عبر Supabase Auth
- **Row Level Security**: حماية البيانات على مستوى الصفوف
- **تشفير البيانات**: جميع البيانات مشفرة أثناء النقل والتخزين
- **إدارة الصلاحيات**: نظام صلاحيات متقدم للمنشورات والتعليقات

### 📊 قاعدة البيانات

#### الجداول الرئيسية
- **profiles**: الملفات الشخصية للمستخدمين
- **posts**: المنشورات والمحتوى
- **post_comments**: التعليقات على المنشورات
- **post_likes**: إعجابات المنشورات
- **friendships**: علاقات الصداقة
- **notifications**: الإشعارات

#### العلاقات
- علاقة واحد لمتعدد بين المستخدمين والمنشورات
- علاقة متعدد لمتعدد للصداقات
